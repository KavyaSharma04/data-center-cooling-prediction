XGBoost ablation study
Dataset: results/hourly_median_merged_data.csv
Chronological split: 70% train / 15% validation / 15% test

Experiment            MAE (kW)   RMSE (kW)   R²
Full model              8.6324     12.1141   0.1911
No time features        8.5135     12.1755   0.1829
No weather features     9.1179     12.9336   0.0780
No IT power             9.0770     14.0365  -0.0860

Interpretation:
Removing time features changed performance only slightly. Removing weather
features worsened all three metrics. Removing IT power produced the highest
RMSE and a negative R², although that run stopped at boosting iteration 0,
so it should be verified before drawing a strong conclusion.

The full model had the best RMSE and R². The no-time model had slightly lower
MAE, so the full model did not win on every metric.
